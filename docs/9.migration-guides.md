---
title: "Migration guides"
description: "What to change in a project when updating @lenne.tech/nuxt-extensions to a new minor version."
---

Every MINOR release comes with a migration guide; a PATCH needs no action (see
[Versioning](./1.getting-started.md#versioning)). When updating, read the guide of every MINOR in between.
Coming from 1.x, start with `1.x-to-4.0.0`.

The guides live in the repository, next to the code they describe:
